python log analyzer:
simple command line log analysis tool written in python
parses log file, structures data, counts log levels, and provides an interactive menu for searching logs by keyword or level

features:
parse logs from text file
count occurrences of INFO, WARNING, and ERROR logs
search logs by keyword
search logs by level
interactive menu

menu options:
1. search logs with keyword
2. search logs by level
3. print counts
4. quit

example output:
enter keyword: user
[INFO] User Sophie is logged in
[WARNING] User attempted access to deprecated endpoint
